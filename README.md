# Редактор графика работы ОАР

Веб-приложение для составления и анализа графика работы операционного блока.
Работает полностью в браузере, без сервера и без интернета.

## Возможности

- Составление графика (постоянные и совместители).
- Проверка ошибок в расстановке.
- Анализ загруженности сотрудников.
- Экспорт в HTML, Excel, Word.
- Сохранение и загрузка в JSON.
- Автосохранение в localStorage.

## Запуск

Требуется [Python](https://www.python.org/downloads/) 3.x.

1. Скачайте папку проекта.
2. Запустите `start_python.bat` — откроется браузер на `http://localhost:8000`.

Или вручную:

```bash
python -m http.server 8000
Как пользоваться
➕ Новый график — выбрать месяц, год и сотрудников.

Клик по ячейке — выбрать код из всплывающего меню.

💾 Сохранить — сохранить в JSON. 📂 Загрузить — открыть сохранённый файл.

🔧 Инструменты — проверить ошибки и посмотреть статистику.

📤 Экспорт — выгрузить в HTML, Excel или Word.
